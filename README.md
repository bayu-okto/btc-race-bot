A long-only BTC trading bot that rides the trend: it buys Coinbase Wrapped BTC (cbBTC) with all its cash on the first bar, holds it, and exits only when two consecutive closes fall 2% below the trailing peak, re-entering on a new high. Built for the make.fun "Race a BTC trading bot live for 24 hours" bounty. Paper trading only — no real money is traded.

## Run it

```sh
node main.ts
```
